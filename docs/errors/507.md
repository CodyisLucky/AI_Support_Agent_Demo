# Error 507

## What the shopper sees

"The payment processor timed out. Nothing was charged. Try the order once more."

They stay on checkout. The cart is unchanged. A new account is not created.

## When it happens

The shop reached the payment processor and did not get an answer in time. Card `4000000000000507` does this on purpose.

This is not a decline (201) and not a processor that could not be contacted (501). A timeout means there is no approval and no charge.

## Likely cause

The processor was too slow, or the demo card was used.

## What to try

Check the account page, or the cart, before trying again. There should be no new order. Then place the order once more. A second try with this same card will time out again, so use a different number if they still have this one. Nothing was charged.

## Log line

`code` is `507`. `user_id` is the signed-in account, or `null` for a guest. `detail` is `last4 0507`.
