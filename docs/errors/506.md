# Error 506

## What the shopper sees

"Your account records could not be loaded. Try again in a few minutes."

On the account page, the name and username still show when the profile itself loaded. The orders section says orders could not be loaded. It does not say they have no orders.

Sign-in shows the same banner when the account file cannot be read. That is not a wrong password (101).

## When it happens

The shop could not read `data/users.json` or `data/orders.json`, or the signed-in username is `recordsdown`. That username can be created and can sign in. Opening the account page then fails to list orders.

## Likely cause

The order file or the user file could not be parsed, or the demo username was used. The shopper may still have orders on disk.

## What to try

For `recordsdown`, tell them this account cannot load its order list. Do not say the orders were deleted. For anyone else, ask them to try the account page again in a few minutes. Do not invent an order from memory.

## Log line

`code` is `506`. `user_id` is the account when they were signed in, or `null` when sign-in could not read the file. `detail` is `username recordsdown`, `read orders`, or `read users`.
