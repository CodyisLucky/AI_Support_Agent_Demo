# Error 504

## What the shopper sees

"The order could not be saved. Nothing was charged. Your cart is still here."

They stay on checkout.

## When it happens

The card was accepted, then the shop could not write the order. Card `4000000000000504` does this on purpose. A real failure writing `data/orders.json` uses this same code.

If they were creating an account in that same checkout and the username was a normal one, the account was created and they are signed in. There is still no order.

## Likely cause

The order file could not be written, or the demo card was used. The payment processor did not decline the card.

## What to try

Look at the account page before they try again. There should be no new order. Then place the order again with a different card number. The cart still has the items. Nothing was charged.

## Log line

`code` is `504`. `user_id` is the signed-in account, or `null` for a guest. `detail` is `last4 0504` or `write orders`.
