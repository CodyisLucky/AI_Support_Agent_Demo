# Error 505

## What the shopper sees

"The order was placed, but the card was not saved to the account."

They land on the order confirmation. The order is real. The saved-card slot on the account is unchanged.

## When it happens

They checked "Save this card to the account" and the card number was `4000000000000505`, or the account file could not store the card. The charge side of this demo accepts the number. Only the save fails.

A guest who does not create an account has nowhere to save a card, so this code does not fire for them. A saved card used again does not fire it either.

## Likely cause

The card vault write failed, or the demo number was saved on purpose. The order itself succeeded. This is not a decline.

## What to try

Open the account page and confirm the order is there and the card is not saved. They can check out again later and save a different card. Do not tell them to place this order a second time.

## Log line

`code` is `505`. `user_id` is the account that placed the order. `detail` is `last4 0505` or `write users`.
