# Error 101

## What the shopper sees

"That username and password do not match."

## When it happens

They submitted the sign-in form and the username and password did not match an account.

## Likely cause

The password is wrong, or the username is not registered. The banner is the same in both cases. The log line distinguishes them: `detail` is `known account` when the username exists, and `unknown username` when it does not. A known account's line uses that account's `user_id`.

## What to try

Sign in again with the username and password for this machine. The seeded shopper is `demo` / `demo-shopper`. If they have no account, create one. Passwords are at least 8 characters.

## Log line

`code` is `101`. `user_id` is the account id, or `null` when the username is not registered.
