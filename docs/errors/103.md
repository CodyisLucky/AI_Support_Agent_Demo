# Error 103

## What the shopper sees

"That username is already registered."

## When it happens

They tried to create an account, on the create-account page or while checking out, with a username that already exists. Usernames are compared without regard to case.

## Likely cause

They already made the account, or someone else on this machine used that username. The seeded username `demo` is taken.

## What to try

Sign in with that username, or choose a different one. Creating an account does not merge two accounts. This code does not mean the password was wrong.

## Log line

`code` is `103`. `user_id` is `null`, because the person who submitted the form is not signed in. `detail` is `username` plus the name they typed.
