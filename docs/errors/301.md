# Error 301

## What the shopper sees

"That order could not be found."

## When it happens

They opened an order link that this browser cannot show. A signed-in shopper can open their own orders. A guest can open an order placed in this browser. Anyone else, including a signed-in shopper opening a different account's order, gets this code. The shop sends them back to the shop.

## Likely cause

The link is from another account, from another browser, or the id is wrong. It can also mean the order is not in `data/orders.json`.

## What to try

Sign in as the account that placed the order, then open it from the account page. A guest order stays on the browser that placed it. Do not read the order aloud from another shopper's account.

## Log line

`code` is `301`. `user_id` is the signed-in account, or `null` for a guest. `detail` is the order id they tried to open.
