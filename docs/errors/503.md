# Error 503

## What the shopper sees

"The account could not be created. Nothing was saved. Try again."

## When it happens

The account passed the usual checks, or the shopper used the demo username `storagefail`, and the account store did not save it. This happens on create-account and on checkout when they choose to create an account.

`storagefail` fails before the password rules are checked. A real write error to `data/users.json` uses this same code. The username `storagefail` cannot be registered.

If checkout also used a special card number, the card result is shown instead. 503 appears when the card itself was accepted and the account write then failed.

## Likely cause

The account file could not be written, or the demo username was used. This is not "that username is already registered" (103).

## What to try

Try a different username. If they used a normal username, try once more. Do not tell them the account exists. It was not saved, and nothing was charged.

## Log line

`code` is `503`. `user_id` is `null`. `detail` is `username storagefail` or `write users`.
