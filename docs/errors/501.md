# Error 501

## What the shopper sees

"The payment processor is unavailable. Nothing was charged. Try again in a few minutes."

They stay on checkout. The cart is unchanged. A new account is not created.

## When it happens

The shop could not reach the payment processor. Card `4000000000000119` does this on purpose. Spaces in the number do not change the result.

This is different from a decline (201). The processor did not approve or refuse the card. It could not be contacted.

## Likely cause

The processor's network is down, or the demo card was used. A saved card does not take this path, because this number is never saved.

## What to try

Wait a few minutes and place the order again, or use a different card number. Do not ask them to re-enter the same number. Nothing was charged, so there is no duplicate payment to look for.

## Log line

`code` is `501`. `user_id` is the signed-in account, or `null` for a guest. `detail` is `last4 0119`.
