# Error 102

## What the shopper sees

"Your session expired. Sign in again."

## When it happens

The browser still had a sign-in, and the shop rejected it. This fires in three cases:

- The shopper loaded no page for 30 minutes. Opening any page after that writes this code.
- The sign-in has no timestamp. A session from before this error step was added does this once, on the next page load.
- The account id in the session is no longer in `data/users.json`.

The cart and any guest order links in that browser are kept. The shopper is signed out.

## Likely cause

They were idle, or the sign-in was left over from an older run of the shop. A missing account is rare and means the user file changed on this machine.

## What to try

Sign in again. The cart is still there. Nothing was charged because of this code.

## Log line

`code` is `102`. `user_id` is the account that was signed in. `detail` is `idle`, `missing timestamp`, or `unknown account`.
