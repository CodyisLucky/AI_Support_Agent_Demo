# Error 201

## What the shopper sees

"That card was declined. Try a different card."

## When it happens

Checkout rejected the card number `4000000000000002`. Spaces in the number do not change the result. The processor answered and refused the card. The shop does not charge a real card.

Other demo numbers fail for a different reason. Those are codes 500, 501, 502, 504, 505, and 507. Do not describe those as a decline.

The order is not placed. A new account is not created on that attempt, and the card is not saved.

## Likely cause

They used the demo decline number. A saved card is not declined, because a declined number is never saved.

## What to try

Enter a different card number. The name, expiration, and security code still have to be filled in. Then place the order again. A number from the 500 series will fail again for a shop-side reason.

## Log line

`code` is `201`. `user_id` is the signed-in account, or `null` for a guest. `detail` is `last4 0002`. The full card number is not stored.
