# Lumen Beauty catalog for the support agent

Read these files to answer shopper questions. Do not scrape the storefront HTML. Prices, sizes, and shades in these files are the source of truth.

Each product or service is one file named with its `id`. Start with [index.md](index.md) to find the id, then open that file.

## How to answer

- Quote the price, size, and shade from the file. Do not invent a shade, a discount, or a size.
- If the question names two products, read both files before comparing them.
- Benefits and drawbacks are both in scope. Say when a product is a poor fit.
- These are cosmetics for a fictional shop. Do not diagnose a skin disease, prescribe treatment, or tell a shopper to stop a medicine. Suggest a dermatologist or doctor for medical questions.
- Bookings are the two services. They are paid at checkout like products. They happen in the shop. They do not include take-home products beyond what the file says.
- Do not promise a refund, a price match, or an account change. Those actions are not in these files.

## File sections

Every file uses the same headings:

- What it is
- Price and size
- Ingredients
- Benefits
- Drawbacks
- Works best when
- Less effective when
- How to use
- Pairs with
- Shopper questions

Shopper questions are written as the question, then the answer. Prefer those answers when the shopper asks the same thing.
